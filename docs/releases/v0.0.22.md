# rlg 0.0.22 highlights

The hand-written part of the 0.0.22 GitHub release. `## What's
Changed`, `## Checksums` and the Full Changelog line are composed at
release time (AGENTS.md, Release Page Format).

## Highlights ⭐️

* **In lockstep with rustlogs.com 0.0.22**: the website joins the family and now ships with the ten crates, its pages rewritten to match this release: minimum Rust 1.89.0, `config` on by default, span context and OTLP span export, and `set_sink` routing.
* **Docs that match the code**: every README and guide was checked against the source. The rlg-mcp README lists its four tools and three transports, every feature is listed with its default, and all five fuzz targets now run on every pull request, replaying their committed corpus first.
* **Dependencies only go down**: a CI gate holds the third-party crates, actions, images and tools to a committed baseline that may only shrink, and `docs/DEPENDENCIES.md` gives each direct crate its reason.
* **A dated deprecation**: running `rlg-mcp` without `--root` keeps working, with a warning, until the first release on or after 2027-02-26, not 0.0.22 as the 0.0.21 notes said. Open deprecations are listed in `DEPRECATIONS.md`. The API is unchanged.
