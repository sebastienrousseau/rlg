# rlg 0.0.14 highlights

The hand-written part of the 0.0.14 GitHub release. `## What's
Changed`, `## Checksums` and the Full Changelog line are composed at
release time (AGENTS.md, Release Page Format).

## Highlights ⭐️

* **Documentation is back online**: the manual and API reference at doc.rustlogs.com deploy again, and every pull request now builds the docs the way docs.rs does, so a new rustdoc lint cannot take the site down unnoticed.
* **Cleaner release pages**: each release carries only the signed SBOMs, not unsigned duplicates next to them.
