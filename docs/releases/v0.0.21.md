# rlg 0.0.21 highlights

The hand-written part of the 0.0.21 GitHub release. `## What's
Changed`, `## Checksums` and the Full Changelog line are composed at
release time (AGENTS.md, Release Page Format).

## Highlights ⭐️

* **rlg-mcp reads only under a log root**: tool paths and globs resolve under `--root` (or `RLG_MCP_ROOT`), so a client can no longer read files elsewhere or probe whether they exist; reads are bounded. Set `--root` to your log directory: it becomes required in 0.0.22.
* **No field can forge a record**: every text format escapes line breaks, terminal escapes and its own delimiters, and journald datagrams use the binary field form, so a message cannot add a record or a journal field.
* **Hardened edges**: OTLP endpoints are validated and DNS respects the timeout, `OTEL_EXPORTER_OTLP_HEADERS` is decoded per spec, log files are created `0640`, rotation keeps every archive, and config debug output hides environment values.
* **Signed MCP image**: the `rlg-mcp` container now carries provenance, an SBOM and a cosign signature, and its publish job pins every tool it downloads.
