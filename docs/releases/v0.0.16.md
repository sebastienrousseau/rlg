# rlg 0.0.16 highlights

The hand-written part of the 0.0.16 GitHub release. `## What's
Changed`, `## Checksums` and the Full Changelog line are composed at
release time (AGENTS.md, Release Page Format).

## Highlights ⭐️

* **The rlg API docs are whole again**: the `rlg` binary in `rlg-cli` and the `rlg` library both documented into `rlg/` (cargo#6313), so the binary's pages replaced the library's and `rlg/index.html` linked pages that returned 404. The binary is now `doc = false`.
* **Docs that search engines index once**: every page at doc.rustlogs.com has a canonical link, `sitemap.xml` lists only the pages the build ships, and `robots.txt` blocks the `?search=` duplicates that Search Console flagged.
* **tokio 1.54 required**: every crate requires tokio 1.54, so no release affected by RUSTSEC-2026-0386 can resolve.
* **MSRV 1.89.0**: the floor rises from 1.88.0 for every crate, one floor shared with the maintainer's other Rust crates.
