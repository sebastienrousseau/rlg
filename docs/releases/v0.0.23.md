# rlg 0.0.23 highlights

The hand-written part of the 0.0.23 GitHub release. `## What's
Changed`, `## Checksums` and the Full Changelog line are composed at
release time (AGENTS.md, Release Page Format).

## Highlights ⭐️

* **rlg formats without std**: the new `rlg-core` crate is `#![no_std]` + `alloc` and holds the log levels, a borrowed `Record` and all 14 formats, written through `core::fmt::Write`. It builds for bare-metal targets such as `thumbv7em-none-eabihf`.
* **Same API, same bytes**: rlg re-exports the level types at their old paths and renders through `rlg-core`, so existing code compiles unchanged and every format test passes unchanged.
* **More checks on every push**: spelling, REUSE licensing for every file, and each feature built on its own, with every feature combination built weekly.
* **In lockstep with rustlogs.com 0.0.23**: the family is now eleven crates and the website.
