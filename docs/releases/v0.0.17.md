# rlg 0.0.17 highlights

The hand-written part of the 0.0.17 GitHub release. `## What's
Changed`, `## Checksums` and the Full Changelog line are composed at
release time (AGENTS.md, Release Page Format).

## Highlights ⭐️

* **One copy of toml**: rlg now requires euxis-commons 0.0.7, which moved to toml 1.0, so a build no longer compiles toml 0.8 and its three helper crates alongside 1.x.
* **No duplicate exemptions left for toml**: the four `deny.toml` skips that hid those duplicates are gone, so a regression would fail `cargo deny` instead of passing silently.
* **Dependencies current**: the GitHub Actions, Docker and minor-and-patch updates merged since 0.0.16 ship in this release.
