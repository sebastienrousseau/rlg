# rlg 0.0.20 highlights

The hand-written part of the 0.0.20 GitHub release. `## What's
Changed`, `## Checksums` and the Full Changelog line are composed at
release time (AGENTS.md, Release Page Format).

## Highlights ⭐️

* **`caller` points at your code**: records from `RlgLayer` named the layer's own source line; they now carry the event's file and line, and an absolute path is cut to start at its crate, so build machines' home directories stay out of log lines.
* **Pick the sink in code**: `rlg::engine::set_sink(PlatformSink::Stdout)` before the first record replaces the journald/os_log default without setting an environment variable after threads have started.
* **Lighter `tracing`-only builds**: file and environment config moved behind a default-on `config` feature. With `default-features = false, features = ["tracing-layer"]`, rlg builds on 33 crates instead of 47, and the satellites no longer pull config back in.
* **Traces continue across services**: a root span created with a W3C `traceparent` field joins the caller's trace. rlg-mcp's SSE transport also refuses messages over 1 MiB before parsing them.
