# rlg 0.0.19 highlights

The hand-written part of the 0.0.19 GitHub release. `## What's
Changed`, `## Checksums` and the Full Changelog line are composed at
release time (AGENTS.md, Release Page Format).

## Highlights ⭐️

* **Span context in `RlgLayer`**: records emitted inside `tracing` spans now carry every enclosing span's fields (including ones filled in later with `Span::record`), the span name and path, and a trace id and span id.
* **OTLP traces without the opentelemetry crates**: rlg-otlp's new `SpanExporter` sends closed spans to a Collector's `/v1/traces` in batches from a background thread, configured from the standard `OTEL_EXPORTER_OTLP_*` variables, with ids that match the log records.
* **Redaction on the `tracing` path**: `RlgLayer::with_scrub(Redactor::with_defaults())` scrubs every record and every exported span's attributes.
* **Three advisories cleared**: rmcp 3.12 (RUSTSEC-2026-0462), rustix 1.1.6 (RUSTSEC-2026-0486), and chrono (RUSTSEC-2026-0543, unmaintained) removed from the tree.
