# rlg 0.0.13 highlights

The hand-written part of the 0.0.13 GitHub release. `## What's
Changed`, `## Checksums` and the Full Changelog line are composed at
release time (AGENTS.md, Release Page Format).

## Highlights ⭐️

* **MCP over HTTP**: `rlg-mcp` runs on the official MCP SDK and serves stdio, streamable HTTP (`--transport streamable-http`) or the older HTTP+SSE transport (`--transport sse`), for protocol revisions 2024-11-05 through 2026-07-28.
* **A smaller, cleaner tree**: 107 crates leave the lockfile. `miette` and `notify` are replaced by built-in diagnostics (`RlgError::code`, `help`, `report`) and a polling hot-reload that also follows editor-style atomic saves.
* **OTLP through a local Collector**: `rlg-otlp` carries no TLS stack. It sends plain OTLP/HTTP to a Collector on `localhost:4318`, which owns TLS and credentials; the blocking exporter now treats a 4xx as final and reports statuses as `BadStatus`.
* **Gates that hold the line**: CI now fails on any `cargo deny` finding across all features, on complexity regressions against a committed baseline, and on install snippets that name the wrong version.
