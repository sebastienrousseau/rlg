# rlg 0.0.18 highlights

The hand-written part of the 0.0.18 GitHub release. `## What's
Changed`, `## Checksums` and the Full Changelog line are composed at
release time (AGENTS.md, Release Page Format).

## Highlights ⭐️

* **Hardened MCP transports**: rlg-mcp's HTTP transports now refuse a foreign Host or a non-local Origin, `/messages/` accepts only `application/json`, sessions are capped by `--max-sessions` (64 by default), and a stdin line past 16 MiB ends the session instead of buffering.
* **Breaking: `rlg::commons` is gone**: the blanket re-export of euxis-commons is removed. Code that reached it through rlg depends on `euxis-commons` directly instead.
* **Fewer euxis-commons features**: rlg moves to euxis-commons 0.0.8 and enables only the error, config, validation, id and counter features it uses, so the retry, time and env modules are no longer compiled.
* **Release pages carry the checksums intro**: the composer prints "SHA-256 of every asset attached to this release:" above the checksums block, which the 0.0.16 and 0.0.17 pages lacked.
