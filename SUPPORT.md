# Support

## Where to look first

- **API reference**: <https://docs.rs/rlg> (and one page per crate).
- **User manual**: <https://sebastienrousseau.github.io/rlg/manual/>,
  built from [`docs/`](docs/).
- **Examples**: `crates/*/examples/`, run with
  `cargo run -p <crate> --example <name>`.

## Asking for help

Open a [GitHub issue](https://github.com/sebastienrousseau/rlg/issues)
with the crate and version, your platform and `rustc --version`, and the
smallest code that shows the problem. The issue templates ask for exactly
this.

Security problems never go in a public issue: follow
[`SECURITY.md`](SECURITY.md).

## What is supported

Only the latest published `0.0.x` release receives fixes (see
[`SECURITY.md`](SECURITY.md)). rlg is maintained by one person; there is
no commercial support contract or response-time guarantee for ordinary
issues.
